# FormatFlip Pro — конвертер видео и аудио

Локальное веб-приложение: MP4/MOV/MKV/AVI/WebM → MP3/WAV/AAC/M4A/OGG/OPUS/FLAC; перекодирование видео между MP4/WebM/MKV/MOV/AVI; преобразование аудио между поддерживаемыми форматами. Конвертация выполняется FFmpeg на вашем компьютере. Загруженные входные файлы удаляются после операции; результат хранится временно до 1 часа, после чего фоновая очистка удалит его. Лимит загрузки — 200 МБ.

Монетизация пока не включена: рекламный блок — только место под будущий код. Условий и выплат нет до допуска рекламной сети, реального рекламного тега, размещения на подходящем публичном хостинге и получения аудитории. Доход не гарантирован.

## Публичное демо

В корне лежат `Dockerfile` и `render.yaml`. Репозиторий уже открыт публично на GitHub; чтобы развернуть: в Render выбери **New → Blueprint**, подключи `Maksumal/formatflip-pro`, просмотри конфигурацию и проверь, что выбран только план Free; затем нажми применить. Не подтверждай оплату или добавление карты. Render Free засыпает после 15 минут без запросов, может просыпаться около минуты, и очищает локальные файлы при остановке/сне. Это демонстрация, не надёжный production-хостинг. Секретов в репозитории нет. Перед публичным использованием пользовательских файлов проверь черновые `/privacy` и `/terms`, добавь реальные контакты владельца и защити сервис от злоупотреблений; не загружай туда чувствительные материалы.

## Быстрый запуск в Windows

1. Скрипт `start.bat` проверит `ffmpeg.exe` в PATH и, если не найдёт, попытается использовать FFmpeg из установленного Hermes на этом ПК. На другом компьютере установите FFmpeg и добавьте `ffmpeg.exe` в PATH.
2. Дважды щёлкните `start.bat` в этой папке.
3. Подождите сообщение о запуске, затем откройте `http://127.0.0.1:5000`.
4. Перетащите файл или нажмите кнопку выбора, выберите нужный формат, нажмите «Конвертировать» и скачайте результат.
5. Чтобы остановить сервер, вернитесь в окно `start.bat` и нажмите Ctrl+C.

Зависимости из `server/requirements.txt` установятся автоматически в локальную `.venv`. Это приложение доступно только на том компьютере, где запущено. Для внешней публикации нужен публичный сервер, который поддерживает Flask и FFmpeg; статический хостинг (GitHub Pages, Netlify static, Vercel static) обработку файлов не выполняет.

## Проверки

Запустите `run_tests.bat` или выполните `.venv\Scripts\python.exe server\test_app.py`. Тестовый набор создаёт короткий реальный видеофайл через FFmpeg, конвертирует MP4 в MP3 через API и проверяет скачивание.

## Реклама и заработок

В `monetize/ads_guide.html` — места для рекламы и краткие шаги подключения. Рекламных показов и дохода сейчас нет: сначала сеть должна одобрить сайт и выдать рекламный код/ID. Вставьте реальный код только от своего кабинета сети; не маскируйте рекламу под кнопки загрузки. Проверяйте требования рекламной сети, cookies/конфиденциальности и применимое законодательство.

## Приватность и безопасность

Файлы обрабатываются локально при локальном запуске; при публичном размещении они передаются вашему хостинг-провайдеру. Не загружайте чувствительные материалы. Приложение не является масштабируемым сервисом: перед рекламным публичным запуском нужны дополнительные rate limits, privacy/terms, проверка безопасности, мониторинг и ресурсы. Не запускайте debug-сервер с открытым доступом в интернет.
